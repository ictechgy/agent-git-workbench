# River 0.1.0-alpha.4

Personal workspace controls for River’s native macOS interface. The interface is currently in Korean.

**[Download the Apple Silicon DMG](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.4/River-0.1.0-alpha.4-macos-arm64.dmg)** · [All release assets](https://github.com/ictechgy/river/releases/tag/v0.1.0-alpha.4)

## Changes

- Save up to 20 named layouts, preview the actual dock tree, and explicitly rename, overwrite or delete a saved snapshot.
- Restore the full screen configuration: nested splits, ratios, tabs, hidden panels, repository navigation and Diff style. Undo restores that same scope.
- Temporarily enlarge a panel while retaining the original mounted tree; return using the visible action, Escape or the View menu.
- Separate screen configuration into Layout, Panels, and Reading/Color. Keep Stash and branches directly accessible.
- Use the native View menu for panel visibility, workspace-edge placement, saved layouts, configuration undo and discoverable shortcuts.
- Adjust code size from 11–20 pt and code/file-list spacing independently of layouts and appearance.
- Keep unreadable preference bytes in a one-time backup and recover valid entries without silently replacing their siblings.

Actual Claude, Devin and Grok design advice and peer discussions informed this slice. Design advice does not certify implementation or performance. Read the [customization guide](https://github.com/ictechgy/river/blob/v0.1.0-alpha.4/docs/customization.md) for the exact saved scope and shortcuts.

## Install

1. Open `River-0.1.0-alpha.4-macos-arm64.dmg`.
2. Drag **River.app** into **Applications**, replacing an older River installation if desired.
3. Eject the disk image, then open **River** from **Applications**.

The download includes the app and Rust engine. Apple command-line Git is required; remote operations need Git 2.41 or later. If `/usr/bin/git --version` fails or is older, install/update Apple's [Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools) or Xcode. The built-in example additionally needs `python3`. No source build is required.

## Compatibility and verification

| Item | This release |
| --- | --- |
| Architecture | Apple Silicon, `arm64`; no Intel or universal2 artifact |
| Declared macOS target | macOS 14 or later |
| Tested runtime | macOS 27.0.1 only; macOS 14–26 compatibility remains unverified |
| Bundle version | `0.1.0`, build `5`; full version `0.1.0-alpha.4` |

The app, bundled engine and DMG are Developer ID-signed. The executables use the hardened runtime. Packaging validation mounts the DMG read-only, copies the app and verifies its signature and architecture. Apple notarization is **not completed**. If macOS blocks opening, review the release status and source; Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445) describe how to proceed if you choose to trust this alpha.

The developer run passed 134 Swift tests and 15 packaging tests. Rust sources are unchanged from alpha.3, retaining its 102-test validation. Native mounted checks verify saved-layout application and full undo, pane enlargement and exact restoration without preference writes, review-filter/draft/selection preservation, and unchanged independently observed Git snapshots. Renders cover the configuration sections, light/dark workspaces, compact large code and minimum-width layouts. Production-view AppKit regressions also verify that hidden commit controls and editors cannot receive keyboard actions, while restored controls and unrelated windows keep working. These are developer checks, not OS-input/VoiceOver certification or large-repository benchmarks.

## Known limits

- No provider PR APIs, general branch checkout, merge/rebase/conflict-resolution UI, discard, stash apply or automatic updates.
- Hooks, external signing programs and external content filters remain disabled/rejected. LFS, submodules and special files retain the limitations described in the [README](https://github.com/ictechgy/river/blob/v0.1.0-alpha.4/README.md).
- Clone/fetch/pull/push are bounded. After a lost response or timeout, inspect local/server state before repeating a write. Closing the client is not confirmed engine cancellation. Recovery notices last for the app session.
- Layouts are global, with up to 20 named snapshots. Undo is session-only; save a named layout before experimenting if you need to recall it after quitting. Per-repository automatic layouts, import/export and arbitrary theme editing are not included.
- The license is undecided; Cargo metadata declares `UNLICENSED`.

## Verify the download

Download the DMG and matching [SHA-256 file](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.4/River-0.1.0-alpha.4-macos-arm64.dmg.sha256) to the same folder, then run:

```sh
shasum -a 256 -c River-0.1.0-alpha.4-macos-arm64.dmg.sha256
```

The [manifest](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.4/River-0.1.0-alpha.4-macos-arm64.manifest.json) records packaging metadata. A checksum does not replace signature or notarization checks.
