# River 0.1.0-alpha.3

Reliability and review-continuity improvements for River's native macOS workspace. The interface is currently in Korean.

**[Download the Apple Silicon DMG](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.3/River-0.1.0-alpha.3-macos-arm64.dmg)** · [All release assets](https://github.com/ictechgy/river/releases/tag/v0.1.0-alpha.3)

## Changes

- Preserve origin-project warnings when a commit or hunk-staging response is lost, without automatically replaying a write.
- Show embedded line controls and bidirectional controls visibly in diffs, retain combining characters and explicit split-diff signs, and keep previous-reading sheets pinned to their captured snapshot.
- Keep cached review content read-only through metadata/reconnect failures; restore the selected staged file after reading Stash and defer scroll restoration until layout is ready.
- Serialize first-time repository registration across app instances and preserve an existing example engine after a failed lookup.
- Keep submitted commit messages exact, make remote/upstream configuration edits atomic, and enforce fast-forward pull even with unusual valid branch names and inherited Git settings.
- Isolate transient IPC connection failures, preserve existing socket-parent permissions, and clean up interrupted recipe waits.
- Bundle the engine reported by the actual Cargo build and reject provenance redirected through inherited Git environment or untracked Cargo configuration.
- Make remote errors visible inside the disclosure, gate new plans during active Git mutations, and expose all recent projects through the application menu.

SSH/HTTPS remote operations and their authentication boundaries remain described in the [remote guide](https://github.com/ictechgy/river/blob/v0.1.0-alpha.3/docs/remotes.md).

## Install

1. Open `River-0.1.0-alpha.3-macos-arm64.dmg`.
2. Drag **River.app** into **Applications**, replacing an older River installation if desired.
3. Eject the disk image, then open **River** from **Applications**.

The download includes the app and Rust engine. Apple command-line Git is required; remote operations need Git 2.41 or later. If `/usr/bin/git --version` fails or is older, install/update Apple's [Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools) or Xcode. The built-in example additionally needs `python3`. No source build is required.

## Compatibility and verification

| Item | This release |
| --- | --- |
| Architecture | Apple Silicon, `arm64`; no Intel or universal2 artifact |
| Declared macOS target | macOS 14 or later |
| Tested runtime | macOS 27.0.1 only; macOS 14–26 compatibility remains unverified |
| Bundle version | `0.1.0`, build `4`; full version `0.1.0-alpha.3` |

The app, bundled engine and DMG are Developer ID-signed. The executables use the hardened runtime. Packaging validation mounts the DMG read-only, copies the app and verifies its signature and architecture. Apple notarization is **not completed**. If macOS blocks opening, review the release status and source; Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445) describe how to proceed if you choose to trust this alpha.

The integrated developer run passed 101 Rust tests, 96 Swift tests and 15 packaging tests. Focused regressions reproduce lost replies, registration races, Git configuration effects, cached review failures and stale build artifacts. Synthetic tests also cover remote configuration, scope and locks, endpoint drift, fetch/prune, fast-forward and rejected pull, exact-branch and rejected push, clone publication, unsafe configuration, late replies and unknown outcomes. Native rendering checks cover the new remote disclosure in light/dark at reference and minimum widths. These are developer checks, not OS-input/VoiceOver certification or large-repository benchmarks.

## Known limits

- No provider PR APIs, general branch checkout, merge/rebase/conflict-resolution UI, discard, stash apply or automatic updates.
- Hooks, external signing programs and external content filters remain disabled/rejected. LFS, submodules and special files retain the limitations described in the [README](https://github.com/ictechgy/river/blob/v0.1.0-alpha.3/README.md).
- Clone/fetch/pull/push are bounded. After a lost response or timeout, inspect local/server state before repeating a write. Closing the client is not confirmed engine cancellation. Recovery notices last for the app session.
- The license is undecided; Cargo metadata declares `UNLICENSED`.

## Verify the download

Download the DMG and matching [SHA-256 file](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.3/River-0.1.0-alpha.3-macos-arm64.dmg.sha256) to the same folder, then run:

```sh
shasum -a 256 -c River-0.1.0-alpha.3-macos-arm64.dmg.sha256
```

The [manifest](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.3/River-0.1.0-alpha.3-macos-arm64.manifest.json) records packaging metadata. A checksum does not replace signature or notarization checks.
