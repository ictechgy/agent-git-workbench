# River 0.1.0-alpha.2

Provider-neutral remote Git operations for River's native macOS workspace. The interface is currently in Korean.

**[Download the Apple Silicon DMG](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.2/River-0.1.0-alpha.2-macos-arm64.dmg)** · [All release assets](https://github.com/ictechgy/river/releases/tag/v0.1.0-alpha.2)

## Changes

- A compact **Remote** (`원격`) control beside the current folder, with fetch/push URLs, fetched branches, upstream counts and remote configuration.
- Clone SSH/HTTPS repositories into a new folder and open them in River. Existing destinations are preserved.
- Fetch branch heads, pull with fast-forward integration, and push the reviewed commit to one branch. Pull/push confirmation identifies the exact folder, local branch, URL and remote branch.
- Detect changed endpoints and local state before submission, preserve commit drafts, and retain an origin-project notice when a write's outcome is unknown.
- GitHub, GitLab, Bitbucket and self-hosted servers use the same Git protocols. Public GitHub and GitLab clone/fetch were exercised read-only in temporary folders; this does not establish every provider/authentication combination.

Authentication uses existing SSH agent/default identities and known-host files, or Apple's Git keychain helper for HTTPS. Provider OAuth/token-entry UI, custom SSH configuration, arbitrary credential helpers, filesystem remotes, URL rewrites, multiple endpoints, partial clones and force push are outside this version. See the [remote guide](https://github.com/ictechgy/river/blob/v0.1.0-alpha.2/docs/remotes.md).

## Install

1. Open `River-0.1.0-alpha.2-macos-arm64.dmg`.
2. Drag **River.app** into **Applications**, replacing an older River installation if desired.
3. Eject the disk image, then open **River** from **Applications**.

The download includes the app and Rust engine. Apple command-line Git is required; if `/usr/bin/git --version` fails, install Apple's [Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools). The built-in example additionally needs `python3`. No source build is required.

## Compatibility and verification

| Item | This release |
| --- | --- |
| Architecture | Apple Silicon, `arm64`; no Intel or universal2 artifact |
| Declared macOS target | macOS 14 or later |
| Tested runtime | macOS 27.0.1 only; macOS 14–26 compatibility remains unverified |
| Bundle version | `0.1.0`, build `3`; full version `0.1.0-alpha.2` |

The app, bundled engine and DMG are Developer ID-signed. The executables use the hardened runtime. Packaging validation mounts the DMG read-only, copies the app and verifies its signature and architecture. Apple notarization is **not completed**. If macOS blocks opening, review the release status and source; Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445) describe how to proceed if you choose to trust this alpha.

Synthetic tests cover remote configuration, scope and locks, endpoint drift, fetch/prune, fast-forward and rejected pull, exact-branch and rejected push, clone publication, unsafe configuration, late replies and unknown outcomes. Native rendering checks cover the new remote disclosure in light/dark at reference and minimum widths. These are developer checks, not OS-input/VoiceOver certification or large-repository benchmarks.

## Known limits

- No provider PR APIs, general branch checkout, merge/rebase/conflict-resolution UI, discard, stash apply or automatic updates.
- Hooks, external signing programs and external content filters remain disabled/rejected. LFS, submodules and special files retain the limitations described in the [README](https://github.com/ictechgy/river/blob/v0.1.0-alpha.2/README.md).
- Clone/fetch/pull/push are bounded. After a lost response or timeout, inspect local/server state before repeating a write. Closing the client is not confirmed engine cancellation. Recovery notices last for the app session.
- The license is undecided; Cargo metadata declares `UNLICENSED`.

## Verify the download

Download the DMG and matching [SHA-256 file](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.2/River-0.1.0-alpha.2-macos-arm64.dmg.sha256) to the same folder, then run:

```sh
shasum -a 256 -c River-0.1.0-alpha.2-macos-arm64.dmg.sha256
```

The [manifest](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.2/River-0.1.0-alpha.2-macos-arm64.manifest.json) records packaging metadata. A checksum does not replace signature or notarization checks.
