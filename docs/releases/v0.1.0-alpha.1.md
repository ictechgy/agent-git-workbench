# River 0.1.0-alpha.1

An early testing release of River, a native macOS Git app for reviewing work across repositories and worktrees. The interface is currently in Korean.

**[Download the Apple Silicon DMG](https://github.com/ictechgy/agent-git-workbench/releases/download/v0.1.0-alpha.1/River-0.1.0-alpha.1-macos-arm64.dmg)** · [All release assets](https://github.com/ictechgy/agent-git-workbench/releases/tag/v0.1.0-alpha.1)

## Install

1. Open `River-0.1.0-alpha.1-macos-arm64.dmg`.
2. Drag **River.app** into **Applications**.
3. Eject the disk image, then open **River** from **Applications**.
4. Choose **Explore the example** (`예제로 먼저 둘러보기`) to try synthetic repositories.

This download contains the native app and its Rust engine. Apple command-line Git is required; if `/usr/bin/git --version` does not work, install Apple's [Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools). No source build is needed.

## Compatibility and verification

| Item | This release |
| --- | --- |
| Architecture | Apple Silicon, `arm64`; no Intel or universal2 artifact |
| Declared macOS target | macOS 14 or later |
| Tested runtime | macOS 27.0.1 only; macOS 14–26 compatibility remains unverified |
| Bundle version | `0.1.0`, build `2`; full release version `0.1.0-alpha.1` |

The app, bundled engine, and DMG have verified **Developer ID Application** signatures with secure timestamps. The app and engine enable the hardened runtime. The DMG was mounted read-only, its app copied and revalidated, and the relocated bundled engine passed startup scenarios with a minimal system PATH. Apple notarization is **not completed**; Gatekeeper assessment reports `Unnotarized Developer ID`.

Apple has not notarized this alpha. If macOS blocks opening because it cannot verify the developer or check the app, review this status and the download source. If you choose to continue, attempt to open River, then use **System Settings → Privacy & Security → Open Anyway** and confirm **Open**. See [Apple's instructions](https://support.apple.com/en-us/102445).

## What ships

- A native SwiftUI/AppKit workspace with configurable panes and light, dark, and system appearance.
- Tasks that prepare branches and linked worktrees across configured repositories while keeping the original checkout in place.
- Changed files, unified or split diffs, text-hunk staging and unstaging, and commits of staged changes.
- Branch and recent-history browsing, linked worktree locations, and read-only stash browsing.
- A built-in synthetic example, task intent and verification records, and copyable requests for external AI tools.

## Known limits

- No fetch, pull, push, general branch checkout, merge/rebase UI, discard, stash apply, or automatic updates.
- Opening a repository through the GUI registers a single-repository workspace. GUI editing/import of multi-repository and recipe configurations is not implemented.
- App-created commits skip Git hooks and are unsigned. External Git filters, including configured global LFS filters, cause affected operations to be rejected.
- Graph/history views show up to 80 commits; diff display is limited to 5,000 lines and 512 KiB. Large-repository performance and VoiceOver behavior remain unverified.
- The license is undecided; Cargo metadata declares `UNLICENSED`.

See the [README](https://github.com/ictechgy/agent-git-workbench/blob/v0.1.0-alpha.1/README.md) and [detailed limitations (Korean)](https://github.com/ictechgy/agent-git-workbench/blob/v0.1.0-alpha.1/docs/limitations.md) before using your own repository.

## Verify the download

Download the `.dmg` and matching [SHA-256 file](https://github.com/ictechgy/agent-git-workbench/releases/download/v0.1.0-alpha.1/River-0.1.0-alpha.1-macos-arm64.dmg.sha256) into the same folder. From that folder, run:

```sh
shasum -a 256 -c River-0.1.0-alpha.1-macos-arm64.dmg.sha256
```

The result should be `River-0.1.0-alpha.1-macos-arm64.dmg: OK`. The SHA-256 file checks that the download matches the published artifact; it does not replace Developer ID or Apple notarization checks. The accompanying [manifest](https://github.com/ictechgy/agent-git-workbench/releases/download/v0.1.0-alpha.1/River-0.1.0-alpha.1-macos-arm64.manifest.json) records packaging metadata.
