# River 0.1.0-alpha.5

Git-safety and keyboard-navigation fixes for River’s native macOS app. The interface is currently in Korean.

**[Download the Apple Silicon DMG](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.5/River-0.1.0-alpha.5-macos-arm64.dmg)** · [All release assets](https://github.com/ictechgy/river/releases/tag/v0.1.0-alpha.5)

## Changes

- Require an exact file scope for hunk staging and reject multi-file patches. A directory request can no longer apply another file’s hunk under the first file’s header. Existing deleted-file, quoted-name and UTF-8 protections remain covered by regression tests.
- Preserve filename whitespace when reading Git repository paths, common directories and worktree control files. A neighboring directory with the trimmed name cannot become the repository identity.
- Deliver the explicit busy response while a client is still sending its request, with bounded request draining and no extra dispatch or handler admission.
- Allow more preflight time for staging and commits while retaining the existing client timeout and bounded Git-write budget. This is a deadline-policy correction, not a large-repository benchmark.
- Preserve original-folder versus task-worktree selection when switching repositories, including folder-specific drafts and task context.
- Make pane tab titles native buttons and add a keyboard-accessible **Select Tab** (`탭 선택`) menu. Selecting a tab keeps its arrangement and does not add an undo step.
- Keep an editor focused while returning from panel enlargement. Hidden-editor and hidden-commit protections remain in place.
- Show control and directional characters consistently in hunk headings, previous-reading snapshots, AI-request previews and split-diff accessibility labels. Copied source, stored checkpoints and staging bytes remain unchanged; altered previews explain that distinction.

## Install

1. Open `River-0.1.0-alpha.5-macos-arm64.dmg`.
2. Drag **River.app** into **Applications**, replacing an older River installation if desired.
3. Eject the disk image, then open **River** from **Applications**.

The download includes the app and Rust engine. Apple command-line Git is required; remote operations need Git 2.41 or later. If `/usr/bin/git --version` fails or is older, install/update Apple's [Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools) or Xcode. The built-in example additionally needs `python3`. No source build is required.

## Compatibility and verification

| Item | This release |
| --- | --- |
| Architecture | Apple Silicon, `arm64`; no Intel or universal2 artifact |
| Declared macOS target | macOS 14 or later |
| Tested runtime | macOS 27.0.1 only; macOS 14–26 compatibility remains unverified |
| Bundle version | `0.1.0`, build `6`; full version `0.1.0-alpha.5` |

The app, bundled engine and DMG are Developer ID-signed. Executables use the hardened runtime. Packaging verification mounts the DMG read-only, copies the app and checks signatures, architecture and payload hashes. Apple notarization is **not completed**. Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445) describe how to proceed if you choose to trust this alpha.

Developer checks passed **119 Rust tests, 144 Swift tests and 17 Python tests**. The Python total includes 15 packaging tests. Regression coverage includes real Git index preservation, whitespace-bearing paths, bounded overload handling, native-window keyboard routing, repository navigation and raw-copy preservation. Deadline tests model elapsed preflight without a real 20-second delay. Native rendering checks use owned offscreen windows. These checks are not OS-input/VoiceOver certification, older-macOS validation or large-repository performance measurements.

## Known limits

- No provider PR APIs, general branch checkout, merge/rebase/conflict-resolution UI, discard, stash apply or automatic updates.
- Hooks, external signing programs and external content filters remain disabled/rejected. LFS, submodules and special files retain the limits described in the [README](https://github.com/ictechgy/river/blob/v0.1.0-alpha.5/README.md).
- Lost replies and timeouts require checking local/server state before repeating a write. Closing a client does not prove that an engine write stopped.
- Entering panel enlargement still resets keyboard focus to prevent hidden input; a visible editor may need to be selected again. Hidden mounted branch panes may continue polling. See [current limits](https://github.com/ictechgy/river/blob/v0.1.0-alpha.5/docs/limitations.md).
- The license is undecided; Cargo metadata declares `UNLICENSED`.

## Verify the download

Download the DMG and matching [SHA-256 file](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.5/River-0.1.0-alpha.5-macos-arm64.dmg.sha256) to the same folder, then run:

```sh
shasum -a 256 -c River-0.1.0-alpha.5-macos-arm64.dmg.sha256
```

The [manifest](https://github.com/ictechgy/river/releases/download/v0.1.0-alpha.5/River-0.1.0-alpha.5-macos-arm64.manifest.json) records packaging metadata. A checksum does not replace signature or notarization checks.
